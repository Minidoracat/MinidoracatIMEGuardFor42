description=[b]⚠️ Two-part mod: subscribing alone does nothing. You also need the small Windows companion tool.[/b]
description=It keeps PZ on an English keyboard while you play and switches back to your own IME when you type.
description=
description=[h2]📦 Requirements[/h2]
description=[list]
description=[*] [b]This mod[/b]: singleplayer and multiplayer; in multiplayer the server must enable it.
description=[*] [b]Companion tool pz-ime-guard[/b]: download from GitHub Releases. Windows only.
description=[*] [b]Game version:[/b] Build 42.20.4+
description=[*] [b]Add/remove mid-save:[/b] safe either way
description=[*] [b]Languages:[/b] 繁體中文, 简体中文, English, 日本語, 한국어, Русский, Español, Português, Türkçe, Français, Polski, Deutsch (please report any translation issues)
description=[/list]
description=
description=[h2]🚀 Quick start[/h2]
description=[olist]
description=[*] Subscribe to and enable this mod.
description=[*] Download pz-ime-guard from [url=https://github.com/Minidoracat/MinidoracatIMEGuardFor42/releases/latest]GitHub Releases[/url] and run it.
description=[*] On first launch SmartScreen appears: click "More info → Run anyway".
description=[*] Once the keycap icon shows up in the system tray, start the game.
description=[/olist]
description=🎬 [b]35-second demo:[/b] [url=https://youtu.be/5q1bfbm3lgU]https://youtu.be/5q1bfbm3lgU[/url]
description=
description=[h2]✨ Features[/h2]
description=[list]
description=[*] [b]English while you play[/b]: movement and action keys stop dying to the IME.
description=[*] [b]Your IME when you type[/b]: chat, search and naming boxes bring back the last IME you used in PZ.
description=[*] [b]Chinese, Japanese, Korean[/b]: guards CJK IMEs and leaves plain keyboard layouts alone.
description=[*] [b]Restore on leave[/b]: your desktop IME comes back when you leave the game.
description=[*] [b]Tray lamp[/b]: a colored lamp shows the guard state at a glance.
description=[*] [b]Autostart and updates[/b]: optionally start with Windows, with automatic update checks.
description=[/list]
