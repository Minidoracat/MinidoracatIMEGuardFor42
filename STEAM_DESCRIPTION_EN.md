[h1]⌨️ Minidoracat IME Guard for B42[/h1]
[h3]By Minidoracat[/h3]

[hr][/hr]

[b]⚠️ Two-part mod: subscribing alone does nothing. You also need the small Windows companion tool.[/b]
It keeps PZ on an English keyboard while you play and switches back to your own IME when you type.

[h2]📦 Requirements[/h2]
[list]
[*] [b]This mod[/b]: singleplayer and multiplayer; in multiplayer the server must enable it.
[*] [b]Companion tool pz-ime-guard[/b]: download from GitHub Releases. Windows only.
[*] [b]Game version:[/b] Build 42.20.4+
[*] [b]Add/remove mid-save:[/b] safe either way
[*] [b]Languages:[/b] 繁體中文, 简体中文, English, 日本語, 한국어, Русский, Español, Português, Türkçe, Français, Polski, Deutsch (please report any translation issues)
[/list]

[h2]🚀 Quick start[/h2]
[olist]
[*] Subscribe to and enable this mod.
[*] Download pz-ime-guard from [url=https://github.com/Minidoracat/MinidoracatIMEGuardFor42/releases/latest]GitHub Releases[/url] and run it.
[*] On first launch SmartScreen appears: click "More info → Run anyway".
[*] Once the keycap icon shows up in the system tray, start the game.
[/olist]
🎬 [b]35-second demo:[/b] [url=https://youtu.be/5q1bfbm3lgU]https://youtu.be/5q1bfbm3lgU[/url]

[h2]✨ Features[/h2]
[list]
[*] [b]English while you play[/b]: movement and action keys stop dying to the IME.
[*] [b]Your IME when you type[/b]: chat, search and naming boxes bring back the last IME you used in PZ.
[*] [b]Chinese, Japanese, Korean[/b]: guards CJK IMEs and leaves plain keyboard layouts alone.
[*] [b]Restore on leave[/b]: your desktop IME comes back when you leave the game.
[*] [b]Tray lamp[/b]: a colored lamp shows the guard state at a glance.
[*] [b]Autostart and updates[/b]: optionally start with Windows, with automatic update checks.
[/list]
